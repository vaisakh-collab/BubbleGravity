
# 🎮 Mystical Cavern

A 2D quiz-based adventure game built with **Godot Engine** and **GDScript**, where knowledge is the key to escaping a mysterious world.

## 🌟 About the Game

You are trapped in a mystical cavern, protected by a fragile bubble. To escape, you must answer questions correctly and rise toward freedom.

But be careful! A wrong answer sends your bubble falling toward danger. An emergency question gives you one last chance to save yourself before you reach the lava.

Explore two fantasy-themed levels, survive timed challenges, and see if you can escape the cavern!

## 🕹️ Gameplay

- **Answer questions:** Choose the correct answer before the timer runs out.
- **Rise toward freedom:** Correct answers help your bubble float upward.
- **Avoid danger:** Incorrect answers trigger a fall toward the hazards below.
- **Emergency challenge:** Answer a quick question correctly to recover while falling.
- **Explore two levels:** Progress from a dangerous lava cavern to a mystical landscape filled with carnivorous plants.
- **Reach the ending:** Survive both levels to reach the victory screen.

## ✨ Features

- Timed multiple-choice questions
- Emergency questions and a falling mechanic
- Fantasy-themed backgrounds and environments
- Intro screen and victory screen
- Level-specific game-over messages
- Two distinct levels with different environments
- Browser-playable version hosted on itch.io

## 🛠️ Built With

## 💻 Run Locally

1. Install the Godot Engine.
2. Clone this repository:

   ```bash
   git clone https://github.com/vaisakh-collab/BubbleGravity
   ```

3. Open Godot's Project Manager.
4. Import the project by selecting its `project.godot` file.
5. Open the project and press **F5** to run the configured main scene.
